# 🌱 EcoConnect - Swadeshi Green Rewards Platform

> **Smart India Hackathon 2025 - Problem Statement ID: 25128**  
> *Student Innovation: Swadeshi for Atmanirbhar Bharat - Clean & Green Technology*

## 🎯 Project Overview

EcoConnect is a comprehensive waste management ecosystem that rewards citizens for eco-friendly actions, connects them with local waste collectors, and contributes to India's vision of Atmanirbhar Bharat through indigenous green technology solutions.

### 🌟 Key Features

- **AI-Powered Waste Classification** - Smart waste categorization using mobile camera
- **Gamified Reward System** - Earn Green Points for every eco-action
- **Hyperlocal Waste Economy** - Connect with nearby collectors and recyclers
- **Carbon Credit Integration** - Convert environmental impact to tradeable credits
- **Swadeshi Manufacturing Connect** - Support local MSME recycling businesses
- **Digital Waste Passport** - Blockchain-based waste tracking transparency
- **Community Challenges** - Neighborhood competitions and campaigns

## 🛠️ Tech Stack

### Frontend
- **React.js** - Component-based UI library
- **Styled Components** - CSS-in-JS styling
- **Framer Motion** - Smooth animations and transitions
- **React Router** - Client-side routing
- **Axios** - HTTP client for API calls

### Backend
- **Node.js** - JavaScript runtime
- **Express.js** - Web application framework
- **MongoDB** - NoSQL database
- **Mongoose** - MongoDB object modeling
- **JWT** - Authentication and authorization
- **Cloudinary** - Image upload and management

### Additional Technologies
- **AI/ML** - TensorFlow Lite for waste classification
- **Blockchain** - Polygon for transparency and carbon credits
- **Maps API** - Google Maps for location services
- **Payment Integration** - UPI for reward redemption

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- MongoDB
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/CoreAstra/SIH128.git
   cd SIH128
   ```

2. **Install root dependencies**
   ```bash
   npm install
   ```

3. **Install all dependencies (client + server)**
   ```bash
   npm run install-all
   ```

4. **Set up environment variables**
   ```bash
   # Copy environment template
   cp server/.env.example server/.env
   
   # Edit the .env file with your configurations
   # Add MongoDB URI, JWT secret, API keys, etc.
   ```

5. **Start the development servers**
   ```bash
   npm run dev
   ```

   This will start:
   - React frontend on `http://localhost:3000`
   - Express backend on `http://localhost:5000`

### Individual Commands

```bash
# Start only the client
npm run client

# Start only the server  
npm run server

# Build for production
npm run build
```
